# Daiva Fauzani — Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Run locally

1. Extract the folder or ZIP.
2. Open `index.html` in a browser.
3. Project preview images and linked PDF files are in `assets/`.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `daiva-portfolio`).
2. Upload `index.html`, `README.md`, and the `assets/` folder to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

## Notes

- The Power BI entry is explicitly labeled as a **dashboard design prototype**. It does not claim that an interactive report or `.pbix` file has already been completed.
- External GitHub and dataset links are included as references.
- Edit `index.html` to update the bio, links, projects, skills, dates, or contact details.
